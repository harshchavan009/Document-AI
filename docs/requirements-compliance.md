## 3. Catalog of Intentional Deviations

1. **Sidebar and Navigation Architecture (B1):**
   - *Requirement:* Left sidebar with logo, New workspace, Overview, Documents, AI Research, Recent activity, Settings.
   - *Implementation:* "New workspace" is housed inside the workspace dropdown switcher; "Home" serves as the Overview; "Document Library", "Research Canvas", and "Settings" are persistent primary sidebar destinations; "Recent activity" is prominently presented on the Home dashboard (`/workspace`).
   - *Rationale:* Elevates user productivity by preventing repetitive sidebar clutter while keeping recent threads and source scope central to the workspace experience.
2. **Settings vs System Technical Specifications Split (B1, G4):**
   - *Requirement:* System parameters and configurations visible in settings.
   - *Implementation:* User preferences (theme, session purge, zip export) reside at `/workspace/settings`; deep pipeline diagnostics (model parameters, top_k, chunk overlap, circuit breaker state) reside at `/system`.
   - *Rationale:* Adheres to core specification rule R2 (not displaying internal developer-facing JSON in the primary user workspace).
3. **Accent Palette Evolution (R2):**
   - *Requirement:* Indigo brand accent in initial draft.
   - *Implementation:* Refined to British Racing Forest Green (`#1b4332`), Warm Amber (`#d97706`), and Warm Paper Light background (`#fcfbf9`).
   - *Rationale:* Eliminates generic AI template vibes in favor of an authoritative, high-trust research aesthetic.
4. **Sample Document Licensing (A9, R3):**
   - *Requirement:* Use a verifiable sample paper.
   - *Implementation:* Attributed "Attention Is All You Need" under its official arXiv open-access distribution license (arXiv.org non-exclusive license), replacing any inaccurate public domain claims.
   - *Rationale:* Enforces the Zero False Claims policy.
