## 1. Project Summary (One-Page Executive Brief)

### The Problem
Traditional generative AI document assistants suffer from two fatal flaws in academic and research environments: **hallucinations** (confidently stating facts absent from the text) and **opaque citations** (offering generic references without verifiable page-level evidence). Researchers and engineers spend excessive time manually cross-referencing AI summaries against source texts to verify authenticity.

### System Architecture & RAG Decisions
DocuMind AI solves this with an evidence-first, retrieval-augmented intelligence architecture:
1. **Deterministic Ingestion:** PyMuPDF extracts text streams with exact page boundaries. A sentence-aware tokenizer chunks text into 600-token blocks with 100-token overlaps, preserving page numbers and chunk sequence metadata.
2. **Persistent Vector Storage:** Chunks are vectorized using Google Gemini `text-embedding-004` (768 dimensions) and indexed in ChromaDB (`chromadb.PersistentClient`) with cosine distance metrics. Every collection is partitioned by workspace and document ID.
3. **Server-Side Citation Validation:** LLM responses generated by `gemini-2.5-flash` undergo automated server-side verification. The backend parses all citation tokens `[X]`, matches them against retrieved chunk IDs, and programmatically strips any citation not present in the vector store.
4. **Untrusted Data Boundary:** Document text is strictly encapsulated inside `[SOURCE X]...[/SOURCE X]` delimiters with system-level instruction defenses against indirect prompt injection.
5. **Session Isolation & Privacy:** 256-bit cryptographically secure pseudonymous session tokens stored in `httpOnly`, `Secure`, `SameSite=Lax` cookies isolate tenant data. A 7-day automated reaper purges expired workspaces, physical files, and ChromaDB embeddings.

### Verification & Testing Evidence
- **Backend Test Suite:** 46 / 46 pytest tests passing (100% pass rate) covering upload validation, extraction, chunking, rate-limiting, persistence, citation filtering, prompt injection, and cross-tenant isolation.
- **End-to-End User Journeys:** 9 / 9 automated Puppeteer browser journeys passing cleanly with 0 uncaught console errors.
- **Accessibility:** 18 automated axe-core WCAG 2.1 AA audits across 9 views in Light and Dark themes with 0 critical or serious violations.
- **Zero Static Data:** All metrics, page counts, models, and limits are fetched from `/api/config` and SQLite database records.

### Honest Technical Limitations
- **Scanned Image PDFs:** Only digital text PDFs and TXT files are processed. Bitmaps and scanned faxes without a text layer trigger an honest refusal error rather than unreliable OCR.
- **Token Estimation:** Non-Latin scripts (e.g. Devanagari) have higher subword density than English, resulting in fewer tokens per chunk unit.
